# Nexus delivery outcomes

- [x] **Responsive personal chat and session history** — The app is named “Nexus”; no multi-user login system is required. It answers text questions, helps with coding, and explains topics. Previous conversation messages are available in the current session, and a clear-chat control clears them. Design is professional, clean and modern: dark navy/slate base, white/light-gray text, a green accent, clean sans-serif typography, and attractive user/assistant bubbles. The layout adapts to mobile.
- [x] **Provider/model selection and manual API-key settings** — Support OpenRouter, Google Gemini, Groq, Hugging Face Inference API, Together AI, Mistral, DeepSeek and Cohere. Each provider has its own key entry in app Settings, plus Tavily. The sidebar lets the user choose provider and model. A provider without a key appears disabled with a key-needed label. Keys can be manually entered after opening the app; the app clearly explains local/session retention and does not save secrets to its server database.
- [x] **Automatic provider fallback** — An Auto Fallback toggle is available. If an API call fails or is out of quota, Nexus tries the next configured provider; image requests only use a vision-capable configured destination. Fallback reports meaningful errors when all candidates fail.
- [x] **Image and screenshot chat** — Provide an image upload control and preview. Send the image with the user's question to a vision-capable model/provider and display the image in chat history for the current session.
- [x] **Research mode** — A sidebar toggle enables search before answering. Tavily has its own key field in app Settings. Search result summaries and source URLs are provided as context to the selected model.
- [x] **Custom app icon and install metadata** — Create a polished Nexus icon, use it as the website favicon and installable-app icon, and provide an app manifest suitable for adding the responsive app to an Android home screen.
- [ ] **Hosted running application** — Implement the complete app in the initialized Manus-managed project, run it, save a checkpoint, and publish it so the user can open it from a link. Explain that an unauthenticated published link is accessible to anyone who has the URL; provider keys must be entered by the user in Settings.
